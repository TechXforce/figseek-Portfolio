## 👨🏾‍💻 About

Modern portfolio website for **Kudakwashe J Chigiya** — IT Technician & Web Developer. Built with a space/moon-landing theme, interactive animations, and a fully functional contact form.

---

## ✨ Features

- 🌍 **Space-themed hero** with rotating Earth and moon surface
- 🔵🟣 **Split-ring animations** around profile pictures
- ⌨️ **Streaming text effects** on hover
- 📊 **Interactive skills section** with per-skill color highlights
- 📸 **Experience timeline** with photo cards
- 📬 **Working contact form** via Formspree
- 🌌 **Constellation particle background**
- 📱 **Fully responsive** design
